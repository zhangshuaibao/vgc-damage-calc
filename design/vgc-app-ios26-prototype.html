交互与信息架构

主计算台

顶部保留格式筛选，主区域始终展示攻击方、防御方和当前招式结果。用户修改任意字段后结果即时刷新，多段伤害用展开行呈现。

编辑模型

  • 攻击方/防御方用分段控件切换，避免手机上同时显示两套长表单。
  • 宝可梦、形态、特性、道具、太晶、招式均使用搜索 sheet，保留使用率排序和拼音搜索。
  • 能力值编辑保留 Base / IV / EV / Boost / 当前 HP，移动端以横向条和数字输入组合呈现。

场地与队伍

  • 天气、场地、光墙、状态、边场、灾祸、气场、空间效果全部保留，多选项用紧凑 chips。
  • 队伍支持六格拖拽排序、添加、删除、复制、剪贴板导入、保存、读取和清空。
  • 设置页覆盖语言、浅深色主题、问题反馈与 GitHub 入口。
